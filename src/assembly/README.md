# igapyon-agent-skills

This archive contains the Agent Skills published by igapyon. The complete
directory for each skill is under `skills/`.

See [INSTALL.md](INSTALL.md) to install or update selected skills in a Codex
skills directory. The root [LICENSE](LICENSE) covers this distribution;
preserve license and attribution files contained within individual skills.

`EXTERNAL_SKILLS.lock` records the repository, pinned ref, and skill name for
externally maintained skills included in this archive.

The project source and build instructions are available in the
[igapyon-agent-skills repository](https://github.com/igapyon/igapyon-agent-skills).
