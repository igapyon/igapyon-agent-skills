# 文章特徴分類レポート

文章特徴分類の標準出力には、次の簡潔な形を使います。該当しない任意項目は削除します。

```markdown
## 文章特徴分類

### 判定

- **対象**: [全文、抜粋、指定節など]
- **入力状態**: [全文 / 抜粋 / 草稿 / 短文]
- **判定状態**: [該当 / 部分該当 / 該当なし / 判定不能]
- **主分類**: [分類名。該当なし・判定不能では省略]
- **副分類**: [意味がある場合だけ]
- **確信度**: [高 / 中 / 低。該当なし・判定不能では省略]

### 根拠

- [分類に効いた具体的な構成、表現、箇所]
- [分類を補強する別の根拠]

### みくく文体

- **状態**: [自然 / 部分的 / 弱い / 対象外 / 判定不能]
- **根拠**: [関連する場合だけ]

### 注意点

- [判断を変え得る未確認範囲、混在、または警告。必要な場合だけ]
```

対象が6分類の外にある場合は、次の形に縮めます。

```markdown
## 文章特徴分類

### 判定

- **対象**: [対象範囲]
- **判定状態**: 該当なし
- **確認できた文章形式**: [小説、契約文、コード断片など]

### 理由

[6分類へ当てはめない理由]
```

入力が不足する場合は、次の形に縮めます。

```markdown
## 文章特徴分類

### 判定

- **判定状態**: 判定不能
- **不足している入力**: [本文、後半、対象範囲など]

### 次に必要なもの

[判定に必要な最小限の入力]
```

ユーザーが詳細評価を明示的に求めた場合だけ、必要な節を追加します。

```markdown
### 分類比較

- [分類名]: [強い / 中程度 / 弱い / 該当なし / 判定不能] — [根拠]

### 補助評価軸

- [判断に効いた軸]: [段階または明示要求時だけ範囲スコア] — [根拠]

### 意図分類との適合度

- **意図分類**: [分類名]
- **適合度**: [強い / 中程度 / 弱い]
- **確信度**: [高 / 中 / 低]
- **解説**: [意図との一致点とずれ]

### 警告

- [高い警告軸だけ]: [根拠と影響]
```
