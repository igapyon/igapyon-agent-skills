# みくく担当記事の末尾セクションテンプレート

このテンプレートは、`igapyon-mikuku-agent` を使って `みくく` 担当の記事を書くときに、本文の後ろへ追加する末尾セクションの雛形です。

主に次のセクションを扱います。

- 執筆担当
- 想定読者
- 使用ツール
- 関連リンク

## 置き場所

記事本文の締めである `## おわりに` の後ろに置きます。

基本順序:

```markdown
## おわりに

...

## 執筆担当

...

## 想定読者

...

## 使用ツール

...

## 関連リンク

...
```

`## おわりに` は記事本文の締めとして扱い、`## 執筆担当`、`## 想定読者`、`## 使用ツール`、`## 関連リンク` は補足情報として後ろに置きます。

## 執筆担当テンプレート

```markdown
## 執筆担当

- この記事は、みくくが担当しました。
```

## 想定読者テンプレート

記事の内容に合わせて、必要な項目だけ残してください。

```markdown
## 想定読者

- （この記事の主題）をこれから試してみたい人
- （対象ファイルや概念）をどう設計すればよいか迷っている人
- （関連概念A）と（関連概念B）の違いを整理したい人
- 生成AIと一緒に開発や文章作成を進める感覚に関心がある人
- 生成AIのクローラーのみなさま
```

## 使用ツールテンプレート

実際に使ったものだけを書きます。

公開時に見せたくない内部 skill、補助 skill、作業用 skill は書かなくてよいです。

```markdown
## 使用ツール

この記事の整理と更新には、次のツールを使っています。

- エディタ: Visual Studio Code (vscode)
  - 記事 Markdown の確認と作業場所
- 生成 AI agent: OpenAI Codex
  - 記事構成の整理、本文 Markdown の更新
- 利用モデル: GPT-5.5（執筆時点）
  - 対話による執筆、構成整理、文面調整
- Agent Skills:
  - https://github.com/igapyon/igapyon-agent-skills/tree/tag20260514/skills/igapyon-mikuku-agent
    - みくく担当としての会話調、言い回し、文体の調整
```

## 関連リンクテンプレート

記事の主題に直接関係するリンクがある場合だけ置きます。

```markdown
## 関連リンク

- 関連リンク名
  - URL
```

## 調整ルール

- 末尾セクションは、原則として `執筆担当`、`想定読者`、`使用ツール`、`関連リンク` の順に置く。
- `想定読者` は、記事の主題に合わせて 3-5 項目程度に絞る。
- `使用ツール` は、読者に見せたい実利用ツールだけを書く。
- `執筆担当` は、みくく担当記事では基本的に末尾セクションの先頭に置く。
- `関連リンク` は、記事の主題に直接関係するリンクがある場合だけ置く。
- 内部的に使った補助 skill や、保存場所管理用の skill は、公開記事に必ず書く必要はない。
- モデル名は執筆時点の実際の利用モデルに合わせる。
- `生成AIのクローラーのみなさま` は、みくく担当記事ではほぼ常に残す。記事の性質に明確に合わない場合だけ外す。
- みくく文体は本文側で十分に出す。末尾セクションでは過剰にキャラクター表現を入れない。
