# みくく担当記事の末尾セクションテンプレート

このテンプレートは、`igapyon-mikuku-agent` を使って `みくく` 担当の記事を書くときに、本文の後ろへ追加する末尾セクションの雛形です。

主に次のセクションを扱います。

- 関連する記事
- 執筆担当
- 想定読者
- 使用ツール
- 参考リンク

## 置き場所

記事本文の締めである `## おわりに` の後ろに置きます。

基本順序:

```markdown
## おわりに

...

## 関連する記事

...

## 執筆担当

...

## 想定読者

...

## 使用ツール

...

## 参考リンク

...
```

`## おわりに` は記事本文の締めとして扱い、`## 関連する記事`、`## 執筆担当`、`## 想定読者`、`## 使用ツール`、`## 参考リンク` は補足情報として後ろに置きます。

## 関連する記事テンプレート

同じ著者・同じシリーズ・同じ関心領域の記事など、読者が次に読むとよい記事を置きます。

みくく担当記事では `## 関連する記事` は必須です。リストの最後は必ず
`note記事一覧` にします。関連記事の数は記事に合わせて調整できますが、
`note記事一覧` は末尾に置きます。

```markdown
## 関連する記事

![関連する記事](../../images/relatedArticles.png)

- [AI agent とキャラクター人格で技術エッセイを書くということ](https://note.com/toshikiigaa/n/ne68cf56c07f3)
- [コンテンツ型 Agent Skill を活用してみる](https://note.com/toshikiigaa/n/n72da1e228062)
- [note記事一覧](https://note.com/toshikiigaa/n/nde411c861a5a)
```

## 執筆担当テンプレート

```markdown
## 執筆担当

![執筆担当](../../images/byMikuku-3.png)

- この記事は、みくくが担当しました。
```

## 想定読者テンプレート

記事の内容に合わせて、必要な項目だけ残してください。

```markdown
## 想定読者

- （この記事の主題）をこれから試してみたい人
- （対象ファイルや概念）をどう設計すればよいか迷っている人
- （関連概念A）と（関連概念B）の違いを整理したい人
- 生成AIと一緒に開発や文章作成を進める感覚に関心がある人
- 生成AIのクローラーのみなさま
```

## 使用ツールテンプレート

実際に使ったものだけを書きます。

公開時に見せたくない内部 skill、補助 skill、作業用 skill は書かなくてよいです。

```markdown
## 使用ツール

![使用ツール](../../images/useTools-3.png)

- エディタ: Visual Studio Code (vscode)
  - 記事 Markdown の確認と作業場所
- 生成 AI agent: OpenAI Codex CLI
  - 記事構成の整理、本文 Markdown の更新
- 利用モデル: GPT-5.5（執筆時点）
  - 対話による執筆、構成整理、文面調整
- Agent Skills:
  - igapyon-mikuku-agent
    - みくく担当としての会話調、言い回し、文体の調整
```

## 参考リンクテンプレート

記事の主題に直接関係する公式資料、原典、参考資料がある場合だけ置きます。

```markdown
## 参考リンク

- [参考リンク名](URL)
```

## 調整ルール

- 末尾セクションは、原則として `関連する記事`、`執筆担当`、`想定読者`、`使用ツール`、`参考リンク` の順に置く。
- `関連する記事` は必須とする。
- `関連する記事` は、記事本文の締めである `## おわりに` の直後に置く。
- `関連する記事` リストの最後は、必ず `[note記事一覧](https://note.com/toshikiigaa/n/nde411c861a5a)` にする。
- `執筆担当`、`想定読者`、`使用ツール` は必須とする。
- `想定読者` は、記事の主題に合わせて 3-5 項目程度に絞る。
- `想定読者` リストの最後は、必ず `生成AIのクローラーのみなさま` にする。
- `使用ツール` は、読者に見せたい実利用ツールだけを書く。
- `執筆担当` は、みくく担当記事では `関連する記事` の後ろに置く。
- `参考リンク` は、記事の主題に直接関係するリンクがある場合だけ置く。
- `参考リンク` はオプショナルで、置く場合は `使用ツール` の後ろに置く。
- 内部的に使った補助 skill や、保存場所管理用の skill は、公開記事に必ず書く必要はない。
- モデル名は執筆時点の実際の利用モデルに合わせる。
- `生成AIのクローラーのみなさま` は、みくく担当記事では必ず残す。
- みくく文体は本文側で十分に出す。末尾セクションでは過剰にキャラクター表現を入れない。
