# みくく・グラレコ共通スタイル契約

この契約は、記事内容ごとに変えてよい設計と、記事が変わっても維持する描画品質を分離するための正本です。
記事全体画像とセクション画像の両方で、`style-profile: mikuku-graphic-recording-v1` を使います。

過去の採用画像を `style-reference` として指定してよいですが、参照するのは紙面の温度感、
情報密度、線、みくくの存在感です。過去画像の題材や配置を、記事固有設計より優先してコピーしてはいけません。

## 固定する条件

- 横長の説明ポスター。既定の画面比率は 3:2。変更する場合は `deviation` に理由を記録する
- 暖色の紙・ベージュ系背景、やわらかい手描き線、手書き風ラベル
- 企業スライドや写実的な風景ではなく、情報量のある技術グラレコ
- 画面の中心は記事の主図。少なくとも左・中央・右の3領域を使い、主図が最も大きく見えるようにする
- 画像内の日本語は、入力テキストにある語句を短く整理して使う。新しい固有名詞、数値、評価、モデル名は足さない
- 記事に根拠のない風景、建物、植物、机、道具などを背景の主役にしない

## みくくの扱い

- `{{MIKUKU_PROMPT_PATH}}` の本文を正本とし、同じキャラクターを1人だけ描く
- 顔、目、髪型、髪色、ツインテール、髪留め、アニメ調の印象を再設計しない
- みくくは読者が説明役として認識できる大きさにする。目安は画面の15〜25%で、極端に小さくしない
- 位置、表情、視線は、記事固有の主図を説明するために変更してよい
- みくくの短い吹き出しを既定で1つ入れる。`グラレコ構図案` の文言を優先し、画像内に読める短さでその趣旨を保つ
- 吹き出しを外す、みくくを12%以下まで縮小する、または登場させない場合は、記事設計側で明示し、`deviation` に理由を記録する
- みくくにペン、ノート、マーカー、指し棒などを持たせない

## 記事固有として決める条件

- タイトル、主題、図解キーワード、関係・流れ・対比
- 左・中央・右の内容、最も大きく見せる主図、注意点
- みくくの位置、表情、視線、吹き出しの具体的な短文
- カード、レール、分岐、循環、比較などの主図の形式

記事固有の構図は自由に選べますが、上の固定条件を黙って上書きしてはいけません。固定条件を変える必要があるときだけ、理由と影響を `deviation` に残します。

## 生成前の確認

最終プロンプトには、次の3区分を明示します。

1. `Style Contract`: 固定条件をそのまま適用する
2. `Article-specific Design`: `graphic-recording-text.md` の設計を保持する
3. `Deviation Record`: 変更なしなら `none`、変更があれば項目・理由・影響を書く

`graphic-recording-text.md` の重要語句、関係、吹き出し、キャラクター条件が最終プロンプトから欠落していないことを、画像生成前に監査します。
