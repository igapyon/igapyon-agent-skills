# Checklist Selection

Use this file only when the task needs a checklist. Choose the smallest matching
viewpoint, then read that checklist directly.

- [../checklists/workflow.md](../checklists/workflow.md): outer system design,
  placement, tooling, MCP, output constraints, and validation planning
- [../checklists/agent-skill.md](../checklists/agent-skill.md): activation,
  `SKILL.md`, references, splitting, and Agent Skill validation
- [../checklists/prompt.md](../checklists/prompt.md): prompt/stable-context
  compaction, output verbosity, structured results, and reasoning load

When multiple layers apply, start with the workflow checklist and add only the
one lower-level checklist required by the selected treatment. For timing, read
[../checklists/checklist-timing.md](../checklists/checklist-timing.md).

Do not read the advanced technique catalog merely to choose a checklist.
