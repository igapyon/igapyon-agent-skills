# Japanese Public Text Final Check

Use this reference for a light final pass on Japanese text before publication
or sending.

This is intentionally modest. It is not a full rewrite skill and should not
override safety, respect, rights, style, or correctness reviews.

## Review Priority

Use this review only when the user asks for final public-text checking, final
Japanese polish, pre-publication review, or a light pass over a Japanese
article, README, release text, post, comment, or message.

Do not activate this review for every Japanese text review by default. Use it
when final-publication polish is part of the request.

## Core Checks

Check lightly for:

- typos
- missing or duplicated particles
- unnatural word order
- repeated sentence endings
- too many commas or awkward comma placement
- inconsistent terms or notation
- inconsistent spelling, capitalization, or product names
- mixed full-width and half-width forms where consistency matters
- repeated words or near-duplicate phrases
- overly long sentences that would be clearer if split
- headings that do not match the section content
- Markdown list formatting that makes the text harder to scan

## Japanese Style Checks

For igapyon writing, also check:

- main explanatory prose uses `です・ます調` when no other style is specified
- polite style does not become too stiff or legalistic
- strong claims have enough scope or qualification
- the text does not become harsher than intended
- bullets may remain fragments when that reads better

Use [writing-style-review.md](./writing-style-review.md) for deeper style review.

## Scope Control

Keep this review small:

- report only issues worth fixing before publication
- do not list every possible micro-edit
- do not rewrite the whole text unless asked
- prefer grouped findings over line-by-line nitpicking for long text
- preserve the author's voice and intended tone

## Review Output

Use this format when a final Japanese text check is requested:

```text
Japanese Public Text Final Check

Findings:
- ...

Small fixes:
- ...
```

When no material issue is found:

```text
Japanese Public Text Final Check

No major typo, notation, comma, sentence-ending, or publication-polish issue
found.
```

If the text needs deeper work than a final check, say so and name the review
that should take priority, such as safety and respect, AI text naturalness, or
writing style.
